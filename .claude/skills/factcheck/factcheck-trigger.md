# factcheck

Before asserting any of the following, invoke the Skill tool with `skill: "factcheck"`:

- a number, date, duration, price, or limit
- a version number, model ID, package name, CLI flag, or env var name
- a function signature, parameter name, return shape, or config key — **including every symbol in code you write**
- a file path, `file:line` reference, URL, or directory structure
- a quote, citation, or "the docs say" / "X supports Y"
- a fact about a named person, company, product, or event

Not for opinions, recommendations, or inferences from what the user told you.

If you are stating one of these from memory and have not opened a source this session, you are guessing. Check, or label it unverified.
